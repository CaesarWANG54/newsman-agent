## Research and Tools

### ExampleLab publishes a document comparison tool

ExampleLab has published a tool that groups document changes and preserves links to the original passages. The example describes a local review workflow.

ExampleLab 发布了一个文档比对工具，可归并修改内容并保留原文段落链接。本例展示本地复核流程。

原文：[合成来源](https://example.com/news/document-review)

### Sample Project adds a multilingual reading view

Sample Project introduces a reading view with English and Chinese summaries displayed together. Original-source links remain available on each item.

Sample Project 新增中英摘要并排阅读能力，每条内容保留独立的原文入口。

原文：[合成来源](https://example.com/news/reading-view)
